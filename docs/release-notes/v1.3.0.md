FacetGlass is a free, open-source OpenFX plugin for DaVinci Resolve (and other OFX hosts) that simulates real glass held in front of the lens: prisms, ghost repeats, split and round diopters, gems and crystals. Every pixel is path-traced through a solid 3D glass object.

## New in 1.3

- **Looks**: a menu at the top of the controls with 16 ready-made starting points (Halo Frame, Rainbow Halo, Echo Row, Ring Echo, Split Diopter, Round Diopter, Prism Edge, Faceted Ghosts, Radial Bloom, Kaleidoscope, Diamond, Amber Jewel, Ice Block, Rain on Glass, Ripple Pool, Bubble Glass). Pick one, then adjust; changing any glass setting turns it back to Custom. See the gallery in the README.
- **On Lens mount** (Placement > Mount): the glass becomes a filter on the lens, so the whole frame repeats through it: rows of copies, circular ghosts, halo rings.
- **Multi-Image Row** shape: an even row of repeats.
- **Playback Cache** (Technical): when the glass does not move, playback replays the traced light paths on each new frame instead of tracing again. On a MacBook-class GPU a 1080p frame went from about 1.6 s to about 24 ms. Replay is a close approximation; by default Final quality always traces in full.
- **Soft Areas** (Technical): blurry parts of the glass are traced at half resolution and filled in smoothly, up to about 3x faster on out-of-focus or frosted glass. Sharp areas are always traced in full.

## Install

**Windows** (NVIDIA GPU recommended; runs on the CPU otherwise): unzip `FacetGlass-Windows.zip` and copy `FacetGlass.ofx.bundle` to `C:\Program Files\Common Files\OFX\Plugins\`.

**macOS** (11 or later): unzip `FacetGlass-macOS.zip`, copy `FacetGlass.ofx.bundle` to `/Library/OFX/Plugins/`, then run this in Terminal so macOS lets Resolve load a downloaded plugin (it is not notarized yet):

    sudo xattr -dr com.apple.quarantine /Library/OFX/Plugins/FacetGlass.ofx.bundle

Restart Resolve. FacetGlass appears under OpenFX > FacetGlass. In Resolve's preferences, set GPU processing to CUDA (Windows) or Metal (Mac). To see the on-screen handles, select the FacetGlass node and set the viewer's on-screen controls (bottom-left of the viewer) to Open FX Overlay on the Color or Edit page.

Tips: set Technical > Input Colour Space to match your footage, start from a Look, and keep Denoise at 0.5.
