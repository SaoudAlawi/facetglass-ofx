FacetGlass is a free, open-source OpenFX plugin for DaVinci Resolve (and other OFX hosts) that simulates real glass held in front of the lens: prisms, ghost repeats, split and round diopters, gems and crystals. Every pixel is path-traced through a solid 3D glass object.

## New in 1.2

- **macOS support.** One universal plugin for Apple Silicon and Intel Macs, rendering on the GPU with Metal. Its output matches the CPU renderer exactly, bit for bit.
- **Inner Reflections** (Glass group): light that reflects back into the glass where it leaves, for faint ghost repeats and gem sparkle. 0 = off, 1 = physical, higher = stronger ghosts.
- **Glass Type**: crown, flint, dense flint, fused quartz, acrylic, sapphire, cubic zirconia, diamond and water, each with its real strength and rainbow spread. Chromatic Aberration 0.4 = that material's real dispersion.
- **Tint** and **Tint Density**: coloured glass whose colour deepens with thickness (amber, emerald, ruby, smoky quartz...).
- **Preview Quality** (Technical group): a lighter quality for the viewer while Deliver keeps the main Quality. Set Quality to Final and Preview Quality to Draft (about 7x faster) or Good.
- **Faster**: parameters read from constant memory on the GPU, nearest-first BVH traversal, and pixels the glass cannot touch pass the footage through untouched.

## Install

**Windows** (NVIDIA GPU recommended; runs on the CPU otherwise): unzip `FacetGlass-Windows.zip` and copy `FacetGlass.ofx.bundle` to `C:\Program Files\Common Files\OFX\Plugins\`.

**macOS** (11 or later): unzip `FacetGlass-macOS.zip`, copy `FacetGlass.ofx.bundle` to `/Library/OFX/Plugins/`, then run this in Terminal so macOS lets Resolve load a downloaded plugin (it is not notarized yet):

    sudo xattr -dr com.apple.quarantine /Library/OFX/Plugins/FacetGlass.ofx.bundle

Restart Resolve. FacetGlass appears under OpenFX > FacetGlass. In Resolve's preferences, set GPU processing to CUDA (Windows) or Metal (Mac).

Tips: set Technical > Input Colour Space to match your footage, and keep Denoise at 0.5.
